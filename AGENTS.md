# Project Guidelines: Islamic App

- **Focus**: Flutter App (`flutter_app`) and .NET 10 API (`IslamicApp.Api`).
- **No Web Preview Servers**: Do NOT run Python HTTP servers or open ports 8000/8080.
- **Frontend Execution**: Native Windows Desktop via `cd flutter_app; flutter run -d windows`.
- **Backend Execution**: .NET 10 Web API via `IslamicApp.sln` or `cd IslamicApp.Api; dotnet run` on port 5000.
